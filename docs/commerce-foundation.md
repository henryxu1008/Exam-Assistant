# 回练收费基础（开发中，未开放收费）

计划提供按考试购买的限期使用权，免费体验与 AI 额度后续分别设计。当前实现了套餐管理界面、服务端配置、订单存储、独立事务结算原语和受保护读取原型；没有真实支付适配器或可启用的完整收费流程。生产云函数硬编码关闭下单和受保护模式，内部结算原语未注册为云函数 action。请勿将本文件视为可收费实现。

每个考试可分别配置 30、90、365 天套餐，商品包含稳定 ID、考试 ID、名称、分为单位的价格、期限、修订及启用状态；服务端读取配置并生成订单快照。每期限日按 24 小时计算，到期前手动购买的套餐接在现有有效期之后，到期后从服务端确认时起算；没有自动扣费。完整退款移除对应订单尚未使用的时长，后续套餐向前接续并保留完整时长。部分退款、订单关闭、优惠券以及对用户展示有效期的完整流程尚未实现，实际退款规则仍需确定。

`shared/commerce-domain.js` 是无存储、无鉴权的纯规则，不校验支付平台签名。`cloudfunctions/commerce/service.js` 绑定云端 OPENID 和有效业务会话，在事务中重验身份；`appConfig/commerceAdmins.openids` 控制商品修改，商品以修订号控制并发，订单价格来自服务器并由账号和请求 ID 保证幂等。`settlement.js` 仅作为内部持久化原语，通过事务将订单、权益和交易号登记一起写入，重放时校验既有权益且退款后迟到的支付通知不会重新开通。

真实支付适配器尚不存在：必须验证微信的通知或主动查询结果，包括支付结果、交易号、金额/商品/身份，再由可信适配器调用内部结算；还需按微信实际协议处理订单号限制、支付/退款通知重试、退款顺序、查单补发和对账。绝不将结算或模拟付款注册成小程序可调用的 action。当前下单禁用由代码固定，不能通过环境变量开启。真实接入前按微信当时的虚拟支付文档验证条件及平台规则。

数据库集合 `commerceProducts`、`commerceOrders`、`commerceGrants`、`commerceEvents`、`commerceTimelines` 均须配置为客户端不可直接读取或写入；管理端和用户端的访问必须经服务端鉴权。订单和权益记录保留原始交付信息，当前有效期以账户及考试对应的时间线为准。当前只做了内存替身测试，没有创建集合、配置数据库规则或验证真实 CloudBase 的事务/并发行为。管理员名单尚无配置界面，运营主体及名单必须在隔离环境核实后配置；本次不进行部署或修改云端配置。

商品管理入口仅对服务端授权的 `commerceAdmins` 可见。管理页只列出经校验的当前已发布考试，每个考试及期限组合使用系统生成的商品编号；名称、价格（精确到分）和启用状态由管理员分别配置。修改采用版本比较，发生冲突或读取失败时不覆盖；页面提供放弃修改并重新载入。商品启用状态仅表示配置状态，不会打开购买或隐藏付费内容。尚未完成原生微信视觉和交互验收。新的商品编号规则不提供旧商品迁移，若环境中已有商品或订单，部署前必须先核实并制定迁移方案。

为在付款前保证结算空间，每个账户和考试的时间线合计最多保留 50 笔已确认期限及待付款预留。当前尚无过期记录归档、待付款订单关闭和支付平台查单对账，预留不会自动释放；达到上限后会在建单时拒绝。必须先完成这些能力并验证不会丢失已付款订单，再考虑开放真实收费。

用户端套餐页提供开发预览：在开发者工具中将 `utils/config.js` 的 `commercePreview` 设为 `true`，从「我的」进入「考试套餐体验」；正式配置保持 `false`。页面可只读查询当前考试的已启用套餐及当前账号有效期，需要隔离环境部署相应版本的 commerce 云函数及准备测试配置。页面内的模拟开通、续费、退款、到期和示例答题使用独立的内存演示数据，离开页面后清除，不调用下单或结算接口，也不保存学习记录；演示不进入正式刷题页。真实支付、用户端受保护题库与账号隔离缓存仍未完成，不能据此启用收费。

新增的在线练习联调页复用题目卡片，仅在 `commercePreview` 和 `protectedPracticePreview` 均为 `true` 时从套餐体验页显示入口。它读取受保护路由中的当前发布和当前考试题目，在加载及提交每题时重新校验账号、发布修订和权益；联网失败、退款或到期后后续请求失败并清空当前题目，账号或考试变更、页面隐藏时也清空。离线不可练习；默认作答不保存，隔离环境额外打开 `protectedRecordsPreview` 后可联调不含题目内容的记录提交及恢复。演示开通不会产生该通道的权益。真实环境服务端受保护路由仍固定关闭，不能通过客户端开关启用。测试使用内存数据库和内部合成结算，不代表部署或真实支付验收。

受保护分页接口每次返回一个源分页内属于该考试的全部题目，页面只展示其中一题，因此单题和提交操作可能重复传输最多 100 道题。错题详情使用单题接口，服务端重新校验身份及权益后才返回当前发布中的该题；旧版错题不会透过本地缓存或历史快照回显。题目版本有变化时明确提示；题目已移除时保留历史事实并提示无法查看。已下发内容无法立即远程收回，退款或过期将在下次请求校验时生效。受保护模式会停止旧题库加载器和 AI 页读取旧内容，但不会删除已下发的历史缓存；启用收费前仍须验证所有部署实例、云数据库规则与受控环境中的旧缓存行为。

受保护学习记录新增独立协议原型：服务端在事务中重验微信身份、学习代次、当前发布、考试归属和权益，从已发布题目判分，仅写入题目及版本 ID、用户作答、得分和时间等事实；不写题干、选项或标准答案。操作 ID 保证同一请求的幂等，历史事实可由本人在权益到期后读取；题目内容仍须通过受保护读取。分页恢复绑定账户、考试、代次及服务端快照序号，任一页失败或快照变化不返回部分结果；客户端当前最多一次恢复 10000 条记录。

受保护在线联调页已接入该协议和按账户隔离的本机待提交队列：操作只含题目 ID、版本、作答和稳定操作 ID，不含题目内容；收到匹配回执后才确认，单账户最多保留 50 条待提交操作。重新进入页面时联网重试队列并恢复完整历史；清空待确认期间阻止重放，确认云端新代次后清理旧代次队列。

在 `protectedRecordsPreview` 开启时，现有错题本和学情页面增加受保护练习区：错题按当前考试的已确认历史错误聚合，点击查看或重练时重新鉴权；学情按考试、科目及章节汇总，未确认作答不计数。登录用户即使权益过期也可读取该考试的目录名称，但不能读取付费题目；科目或章节已移除时标记为已移除。普通练习与受保护练习分开展示，避免在不同协议来源尚未完成统一去重时重复合并。客户端 `protectedCatalog` 为真时，普通错题和学情视图被隐藏、旧练习会话不再读取本机题目快照；统一首页可读取账号绑定的考试及科目目录，选择后进入受保护在线练习，服务端逐题校验免费或有效付费权限；无权限时可查看套餐。目录仅在内存中保存，账号或数据代次变化时失效；旧练习方式不会自动转换。这个受关闭开关保护的原型不代表完整的免费/付费混合练习已完成。受保护错题支持收藏、标记和取消掌握，以及待复习分类；答错后自动取消掌握。复习日期从服务端已确认作答推导：错后一天，连续答对后依次按 1、3、7、14、30 天安排；它使用设备本地时间展示，不会自动推送提醒。学情页另列近 7 天趋势，未与旧统计混算。AI 助教在受保护模式暂时关闭，避免旧对话或本机快照回显。

`protectedAttempts`、`protectedStudyHeads`、`protectedQuestionStates` 和 `protectedStateReceipts` 均须禁止客户端直接访问；分页查询依赖账号、代次、考试和序号组合的云数据库索引，尚未在真实 CloudBase 环境创建或验证。清空旧代次记录的物理清理代码已有合成测试，但 `studySync` 中的 `PROTECTED_RECORDS_ENABLED` 固定为 `false`；正式启用时须与 `bankSync` 受保护模式及云数据库规则协调发布，验证清空失败重试和旧实例混用。`PROTECTED_STUDY_ONLY` 也固定为 `false`，启用时拒绝旧记录接口、仅提供鉴权后的数据代次，必须与受保护读取和清理同时协调启用。所有相关模式目前均关闭。

当前题库的发布、分页和历史版本接口可返回完整题目；付费内容必须先改造所有读取路径和数据库规则，并处理本机缓存、账号切换、离线与退款，再开放商品。已下发的内容无法保证绝对防复制。学习记录属于独立领域，权益过期或退款不应删除记录；该行为仍待端到端实现与验证。

`shared/exam-page-projection.js` 可先验证原发布和原始完整分页，再按考试归属过滤题目，保留原发布 ID 与题目版本。受保护读取原型在一次事务中重验身份、绑定当前发布的访问策略、账户及考试的有效期限、发布归档和原始题目页后，才返回当前考试的题目；免费考试也需要明确策略。策略、权益或题目读取失败均拒绝。所有考试策略合并为一个带摘要的文档，必须完整覆盖当前发布的所有考试并匹配发布修订，避免缺失时默认免费。读取不依赖客户端指定订单，尚无用户订单列表或完整客户端接入；此原型不提供历史发布访问。

`bankSync` 增加了受保护模式路由：开启时拒绝旧公开读取及旧版发布接口；受保护读取 action 只能使用微信运行时身份。受保护分页草稿必须声明每个考试的访问规则，规则摘要与草稿、逐页阅读和独立审核回执绑定；审核人需读取并确认规则。通过审核的发布在一个事务中写入策略、发布指针及审核记录，发生失败时回滚。旧模式草稿不能用受保护流程发布。受保护发布最多 19 页、每页最多 100 题，按现有事务操作预算留出策略读写空间；实际题数受分片大小影响，可能低于 1900。

该模式目前在服务端代码中固定关闭，客户端的策略界面也默认关闭，因此当前部署仍可走旧公开接口。管理端已实现选择每个考试免费/付费、展示策略并独立审核；新增考试必须明确选择，载入当前发布时继承已审核策略。模拟测试覆盖逐级创建、设置、审核、发布及重新载入；微信原生界面尚未验收。

尚未实现受保护缓存或真实购买。启用前仍须完成数据库直接读取的保护、客户端账号缓存隔离和端到端测试；所有云函数实例必须先同步更新，防止旧实例绕开保护。新旧协议混用不应被理解为已保护内容。真实云数据库事务上限、事务冲突重试、读取/退款并发及权限规则尚未验证。

题库来源授权、用户协议、隐私政策、收费及退款规则均须在实际运营前核实并填写运营主体和联系方式。用户确定的小程序名称为“回练”，不等同于运营主体的法律名称。

受保护首页目录和科目入口只用于隔离联调；服务端相关入口依旧固定关闭。旧公开接口的阻断代码已准备但尚未在真实环境启用，本机已下载内容无法收回，云数据库直接访问规则及所有实例协调切换仍须验收，不能单独打开客户端开关作为收费保护。当前选择只保存在内存中，重新启动需重新选择；题库、权益变更及账号切换均以服务端校验和当前会话为准。

收藏与掌握状态按账号、考试、学习代次隔离，采用整份状态修订号检测并发；同一操作 ID 的回执可幂等重放，读取或写入失败不视为成功。单考试状态最多 2000 个题目且序列化后最多 400000 字节；多个设备同时修改不同题目也可能冲突，需要重新载入后再操作。回执目前随学习数据清空处理，长期归档与真实数据库容量、事务并发仍需验收。

数据库逐集合拒绝客户端访问的审核规则、候选索引、适用范围和隔离验收步骤见 [`cloudbase/protected-access`](../cloudbase/protected-access/README.md)。该目录仅含审核清单，尚未创建索引或应用规则；本地合成测试不能验证 CloudBase 实际规则和查询计划。
