备份和不可变页带来额外空间；大历史的同步迁移会阻塞 JS。空间或准备失败时可延期并完整保存原格式，
不保证每台设备都立即切换。部署前需验证实际配额、等待反馈和中断恢复；不能把写入减少当成总存储减少。
原始 JSON 保留每个样本的 before/after bytes、迁移、序列化、提交及 heap 观测。heap 是离散采样，受 GC 影响，不是峰值。
