# 管理端 AI 候选题生成

状态：代码与合成测试；默认关闭，未部署，也未进行真实模型调用或微信设备验收。

## 操作

具有题库编辑角色的管理员在可视化编辑器载入题库，选择科目、章节，填写知识点，选择单选、多选或判断、难度 1–3 和数量 1–5，再生成候选题。界面显示每题题干、选项、答案及解析。候选题仅保存在当前页面内存，离开页面、切换账号或丢弃后不会保存；重新生成可能再次消耗配额。

核对候选后填写真实的题目依据及使用权说明，点击“加入当前编辑”。系统在一次本机工作区提交中加入整批题及 AI 来源，不修改已发布题库；题目可继续在编辑器逐题修改，随后沿用完整题库草稿、另一人独立审核来源和答案、按发布基线发布。编辑器检查与工作区已有题面完全一致的重复（忽略大小写、空白及 Unicode 兼容形式），不保证发现语义相似题。候选数量、格式、章节、答案、题型、长度和相同题面异常均整批拒绝；AI 解析与事实正确性仍由人工核验。

切换账号、页面隐藏、编辑工作区或章节改变后，旧结果不能加入新工作区。本机检查点失败时不显示加入成功；过期的题库发布基线仍由现有草稿和发布流程拒绝。模型不能指定或覆盖题号、科目、章节或来源；题号由服务端根据账号与请求 ID 生成，来源由管理员填写并与草稿绑定。

## 服务端配置和权限

独立云函数 `aiQuestionGen` 默认停用。仅服务端环境变量指定 HTTPS、兼容 Chat Completions 的服务地址、模型和凭据；客户端不能传地址、凭据或模型：

- `AI_QUESTION_ENABLED`：明确设置为 `true` 才启用。
- `AI_QUESTION_ENDPOINT`、`AI_QUESTION_MODEL`、`AI_QUESTION_API_KEY`：在授权的云函数环境安全配置；不得放在小程序、Git 仓库或日志中。
- `AI_QUESTION_DAILY_CAP`、`AI_QUESTION_USER_DAILY_CAP`：UTC 日全局和单用户调用次数，默认分别 50 / 10，必须为正整数；在事务中共同预约，失败不放行上游。

每次外部请求前确认个人 token、题库编辑角色并预约额度，模型调用结束后再次确认身份与角色。权限撤销、配额读取或写入失败、上游超时、超大响应、解析或校验失败均返回明确错误，不返回不完整题目。额度在调用前预约，**上游失败或响应丢失也可能消耗一次额度**；重复点击是新的调用。数据库规则须禁止小程序直接读写 `aiQuestionUsage` 和角色配置，仅允许函数写入配额。

发送给模型的仅是所选考试、科目、章节名称、科目及章节标识、知识点、题型、难度、数量及随机请求 ID，不包括登录令牌、学习记录、已有题目、题目来源或授权说明。管理员填写的知识点会发送给所选服务商，不应包含不应外传的敏感内容；启用外部模型前应核对服务商处理方式及适用的告知要求。候选生成服务不访问真实题库集合、不存储模型输出、不写入学习数据。

先在独立环境验证云函数权限、事务、数据库规则、费用限制和模型响应；真实环境配置、部署和付费调用须按实际授权另行执行。当前验收仅使用模拟模型及内存数据库，不表示真实模型或原生环境已验证。
