# ADR 0016：迁移容量准入与可观察的本地恢复（Issue #11）

- 状态：Implemented，未部署；微信隔离环境验收待完成
- 前置：ADR 0015；物理格式仍为 v4，领域快照仍为 v3，应用版本仍为 1.1.0

## 根因与决策

分段减少正常作答的写入量，但迁移会同时占用旧根、首次备份和新分段。
仅等写入抛错才延期，仍会进行大量注定失败的准备写入。另一方面，成功读到旧检查点不能证明上次写入成功。
修改前的合成故障测试复现了容量不足仍写备份/页，以及读取后 write_error 被清除。

迁移先在内存完成有界页规划，再在任何备份/新页写入前读取 getStorageInfoSync 的 currentSize / limitSize（KB）。
使用整个小程序当前占用，包含其他账号和非学习缓存，不只计算当前账号。
本次新增页、缺失的首次备份和完整新根，以 key + JSON 的 UTF-8 字节按 KB 向上取整；额外保留 max(64 KiB, 计划量的 10%)。
新根不抵扣旧根，未提交前不会借用预期清理出的空间。容量不足或信息未知时直接保存完整旧格式候选状态，标记
migrationDeferred / migrationError，不写备份和新页，不删除已有备份、不裁剪事实或 outbox。

预算是保守准入估算，不是原生序列化/可用磁盘的精确保证，也不覆盖单 key 大小限制。
准入后实际存储仍可能失败，沿用准备失败退路和根结果不确定保护。
只可移除本次创建、尚未被根引用的准备内容；已有备份不会因准入延期被移除。
备份从未被当作最新状态使用；延期也不保证后续每次旧格式写入有足够空间。

参考：[微信 Storage 信息](https://developers.weixin.qq.com/miniprogram/dev/api/storage/wx.getStorageInfoSync.html)、
[微信同步写入](https://developers.weixin.qq.com/miniprogram/dev/api/storage/wx.setStorageSync.html)、
[腾讯云官方同名 API 说明](https://staticintl.cloudcachetci.com/doc/pdf/product/pdf/tencent-cloud_1219_68005_en.pdf)。
以运行时返回额度进行准入，不硬编码总配额。Node 基准刻意使用充足的合成额度，不宣称 1 万条基线能放入微信原生存储。

## 状态和重试

仓储独立记录 readError 和 writeError；成功读取不会清除写错误，直到完整写入成功。
写入前验证完整旧检查点，读失败保持 read_error，后续 flush 失败不能降为普通写错；读错误只在证据校验成功或完整检查点提交后解除。
根写入被调用后抛错（包括原格式、延期退路、清空和回滚）标记 commitUncertain，避免通用重试用旧内存覆盖可能成功的新根。
状态变化只通知当前账号的订阅者，订阅者异常不改变写入结果。

“我的”页区分本地可用、优化延期、读取失败、保存失败、保存结果待核对和清理待完成。
读取失败时隐藏旧统计与清空入口，保留当前账号身份并提示保留现场；不把异常展示成空学习档案或已完成云同步。
可见性同时取决于 getter 成功、仓储非 read_error 且无 readError；已有内存缓存和后续失败 flush 不能让刷新绕过读取失败保护。
写入失败的原始错误、题目、答案和账号标识不会进入状态文案。

store.retryLocalStorage 是同步的本地检查/重试：先冷校验现有引用，再尝试当前完整状态；不发起云端调用，不自动恢复旧备份，
不自动清空、回滚或重新安装。dirty 数据只有保存成功才清除标记；延期和清理未完成分别返回未完成。
若失败的是未接受的原操作且没有 dirty 状态，要求返回原操作重试；作答不会凭空补造。
commitUncertain 要求关闭并重开当前代码，核对实际检查点后再继续。它不提供在同一进程中盲重写的按钮。
页面隐藏/卸载后不更新提示。登录删除意图已接受但本地清空未完成时，显示待处理，不能提示已清空。

## 自动化证据与实际设备验收

- 强制配额的合成适配器覆盖空间不足、信息未知、准入后空间变化、旧格式退路失败和已有备份保护。
- 页面组合测试运行真实 store，验证延期→重试、不可读→修复介质→本地重试、生命周期和无云调用。
- 子进程在迁移、清空、回滚的每个存储修改前/后 process.exit，绕过 catch/finally；共 30 个退出点。
  重启校验完整领域快照、待传操作及其他账号；再次迁移/清空/回滚仍可完成。
- 写后报错再重启，原操作重试幂等，通用重试不覆盖已保存事实。
- 继续运行原离线、跨设备、账号切换、恢复/确认和管理员权限回归。

子进程测试只模拟 API 边界的进程消失，不模拟原生半写、设备断电或介质破坏；文件仅为可丢弃的合成临时数据。
本阶段未降低首次迁移全部 CPU/内存开销，未分段 AI 或待传历史，未增加自动损坏修复或备份导入按钮。

实际微信开发者工具及隔离测试设备需使用合成账号/数据，逐项记录：

| 场景 | 验收点 | 当前状态 |
| --- | --- | --- |
| 额度不足/额度未知 | 延期提示；没有备份/页准备写；完整候选状态保留 | Node 已验证，微信待验收 |
| 原格式也无法保存 | 作答不完成、可再次提交；保存错误保留 | Node 已验证，微信待验收 |
| 缺页/损坏 | 保留现场；不显示空档案；重试不能覆盖 | Node 已验证，微信待验收 |
| 写入阶段关闭应用 | 冷启动旧/新根完整，outbox 不丢、其他账号不变 | API 边界已验证，原生中断待验收 |
| 原生单 key 限制、迁移等待与内存 | 无假成功；记录实际耗时和配额；必要时延期 | 待验收 |
