# ADR 0019：考试题库编辑与审核发布（Issue #5）

状态：代码阶段，未部署；真实 CloudBase、微信 UI 和多身份验收待完成。

## 数据和发布

schemaVersion 3 的 manifest 包含 exams 与 subjects，每个科目必须引用明确考试 ID；章节及题目仍归属科目。
考试归属进入 releaseId 摘要；题目原内容的 versionId 沿用原规则。来源与完整内容进入不可变草稿摘要，
用户选择的编辑、独立审核、发布角色仍在事务内重新验证。

考试题库使用 createExamDraft / publishExamDraft / getExamPublished，普通导入或旧写接口不能静默丢弃考试字段。
修改已发布内容必须绑定 basePublication，在创建和发布事务内检查修订及 releaseId；并发发布使旧草稿失效。
审核人与提交人必须不同；已批准内容、来源、收据和归档不可原地改写。空题库草稿拒绝，避免误清空。

getActiveCatalogDraft 在身份和目录角色校验后读取当前发布、发布审计和关联草稿，核对摘要、修订和来源。
读取失败、缺少证据或损坏均明确失败，不能以空题库作为编辑基础。
学习同步对发布归档检查 v3 摘要并按原题判分；学习端验证完整发布并落盘成功后才切换数据源。

## 操作与边界

个人页的管理入口仅在当前身份获得目录角色后显示，服务端仍执行权限校验。
编辑器在内存中加载完整发布与私有来源，按考试、科目、章节和题目编辑；各操作不会直接写云端，
完整校验和授权确认后提交草稿。更改、表单未保存、重载和切账号会作废准备结果或阻止误提交。
来源、答案和题目内容不放入脱敏日志。新旧代码协调发布和历史归档处理应在独立隔离环境验证，
本阶段不以旧客户端兼容作为交付要求。

当前底层题目和统计仍按科目名称关联，科目名称必须全局唯一；同名科目不能跨考试分别创建。
学习页当前列出全部科目，尚未提供考试选择及按考试隔离统计。考试格式批量导入、分页、管理列表、
大于页面 400 KB 的完整工作区和复杂填空分隔符输入尚未支持，均不能通过截断内容处理。
编辑内容保存在当前页面内存；退出页面前须先提交草稿或保留原始输入。

## 验证

合成回归覆盖 v3 身份、权限、完整来源、独立审核、过时基线、学习端读取和服务端判分，
以及页面表单、空分类保护、权限入口与账号切换。Node 替身不构成真实微信界面、数据库规则、
原生事务容量或多设备验收。未部署云函数或修改真实题库、运营配置与学习数据。
