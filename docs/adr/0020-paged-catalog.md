# ADR 0020：分片题库的审核与原子发布

状态：代码与合成测试阶段，尚未部署；真实 CloudBase 和微信设备容量、数据库规则及事务限制待验收。

## 问题和边界

v3 的题库、私有来源和发布归档均为单文档，受 500 题、600 KB 题库和 160 KB 来源限制。v4 将内容拆成公开题目页和仅目录角色可读的来源页，单页各不超过 120 KB；根清单绑定页顺序、题号范围、数量、题目摘要和题号身份摘要。来源摘要及来源内容只存在于私有草稿，公开接口不返回来源。

为能在一次发布事务中重新读取所有页并核对审核证据，首版最多 **20 页、每页最多 100 题、总计最多 2000 题**。单题较大时，单页字节上限可能先触发，因此实际题数可能小于 2000；题号登记的所有分片合计超过 1 MB 或单分片超过 750 KB 也会停止发布。管理页文件输入最多 12 MB。以上均为应用侧工程上限，不代表真实平台额度已验收。

## 草稿和发布

编辑通过个人身份创建绑定当前发布修订和 releaseId 的草稿。每次上传一对题目/来源页；内容、范围和摘要都必须匹配，页及题号分片与草稿进度同事务提交。相同提交 ID 和相同页可重试；不同内容不能占用相同提交 ID。

全部页上传后，封存检查题号身份摘要和基线；审核人逐页读取题目及其来源，服务端记录本人访问进度，所有页访问后才可批准；提交人不可自审。发布人按原基线发布时，再次核对当前角色、审核收据、所有题目/来源页和题号登记，在同一事务写入新登记、发布归档、审计和活动根。缺页、校验失败、身份复用、权限撤销、过时基线或中途写失败均不能激活。

公开分页读取要求存在有效的已发布归档，并验证页摘要；未发布草稿页不可通过此接口获取。数据库规则必须禁止客户端直接读取或写入 questions 集合中的私有来源、草稿、题号登记和暂存页，也必须禁止绕过云函数修改发布归档。仅靠页面权限隐藏不能替代数据库规则。

题号身份与 v3 保持一致，撤回题号仍永久保留；旧显示名称身份的 v2 发布不能直接转换。已发布的 v3 可作为基线更新为 v4，旧单文档发布不能覆盖 v4。v4 撤回仍由编辑创建完整新快照，随后独立审核发布；不支持直接复用已撤回题号。

## 客户端和判分

学习端按发布 ID 并发拉取有限数量的页，校验全部页和身份摘要，再重新确认当前修订，先落盘分片、最后切换根指针。缺页、坏页、网络和写盘失败保留当前完整版本；重启后重新验证本机分片。缓存根验证通过后，学习端可在安装前后回收未被当前根引用的旧页及中断暂存，只处理严格匹配题库页命名空间的键；正在安装的发布受进程内标记保护。编辑器可按账号清理没有被当前校验通过的工作区引用且没有正在写入的分片。读取、清单或校验失败时跳过回收，不能触碰学习数据与待传队列。该协议依赖全部缓存读写运行在当前小程序主 JS 上下文且同步 API 不跨上下文并行；若未来引入 worker 或多独立 JS 上下文共享存储，必须先引入跨上下文互斥或重新设计，禁止沿用当前回收逻辑。

作答快照保留分页协议标记和原 releaseId。`commitPagedAttempts` 按原发布的根清单定位并校验题目页，再在事务中判分；不依据当前发布或客户端自报分数。分页版每批最多 19 条，保证模拟最坏情况下数据库操作数不超过 100；缺页、错误摘要和读取失败不会确认或删除待传事实。

## 运营和待验收

管理页支持以 UTF-8 JSON 文件全量导入 v4，也可读取已发布的审核记录及逐页私有来源，逐题可视化编辑并生成完整新草稿。载入完成前检查全部页面及发布基线，来源缺失、损坏或基线变化时拒绝载入。编辑工作区分片保存在当前账号本机，根指针最后更新；存储故障保留之前已提交的本机快照，实际设备配额仍可能限制可编辑容量。提交可用同一提交 ID 中断续传。分页草稿可逐页审核，撤回会重新生成并审核完整快照。离线预检命令只输出数量、发布摘要和不含题面/答案/私有来源的错误定位。

编辑人可明确丢弃本人尚在上传且未封存的分页草稿：事务内核对私有来源页和身份暂存分片后删除，仅保留带丢弃状态的草稿记录；封存、审核及发布后的证据不删除。每个发布内容 ID 另有事务保护的引用登记：创建草稿递增，丢弃未封存草稿递减；封存、拒绝或发布的草稿继续保留引用及证据。创建人与清理操作都更新同一登记文档，确保并发序列化；草稿创建人可清理其已丢弃草稿的公开题目页，前提是引用数为零且无发布归档或活动发布。读取失败、登记损坏和页校验失败均阻止清理，整批删除与登记更新在同一事务中。该登记属于新协议，部署前环境须为空；已有分页数据不能直接接入，需单独设计和核对登记重建。

合成测试覆盖 700 题文件导入、审核、发布和按原题判分，以及超过 800 KB 的逐题编辑、重启恢复、暂存事务回滚、同发布多草稿及清理与新建并发、本机中断回收与隔离，2000 题/20 页最大事务预算、页缺失/篡改、读写故障回滚、过时基线、权限撤销、题号撤回、离线重启及补传。以上不构成真实平台事务隔离、响应大小、文件 API、本机存储配额或多设备验收；无部署、真实数据或运营配置写入。
