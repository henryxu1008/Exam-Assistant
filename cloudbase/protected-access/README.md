# 受保护题库：规则与索引审核方案

**仅用于代码评审，不会自动应用。** 本目录不包含环境 ID、凭据、云端写入脚本或可直接运行的部署配置。所有开关维持原状；当前公开题库接口仍会返回完整题库，不能开启收费。

- `deny-client.rule.json` 是一份集合级 CloudBase 安全规则：`read`、`write` 均为 `false`。`manifest.json` 中列出的每个集合都拟单独应用这一规则。此规则不影响服务端云函数、管理员控制台权限；它不能取代云函数内部的身份、角色和权益校验。
- `manifest.json` 是**本项目自定义的人工审核清单**，不是 CloudBase CLI、SDK 或 Terraform 的配置格式。索引均为非唯一候选项，`keys` 数组顺序和方向对应代码查询；与现场现有索引、配额和查询计划逐项比对后再决定是否创建。自动 `_id` 索引、`_id` 参与组合索引的支持情况以及 `exists(false)` 的实际索引命中仍待在目标 CloudBase 环境核实。不要把通过本地测试理解为规则已生效或索引已创建。
- `questions` 集合既包含付费题目，也包含题库草稿、私有来源和历史发布；不能只保护新建的受保护学习集合。`users`、`appConfig`、旧 `attempts` / `studyStats` 以及订单权益集合也不得遗漏。现有代码中登录、公开运营配置、题库管理、商品管理和学习记录通过云函数访问，客户端未发现直接数据库访问；上线前仍须对实际发布版本和第三方调用者重新核实。
- `users.token` 不设置唯一索引：登出用户可能共享空令牌。其他候选索引也不引入新的唯一约束。题目和权益按文档 ID 的读取依赖系统 ID 索引；受保护历史分页候选索引为 `(openid, dataEpoch, examId, sequence)`。各清理集合候选索引以 `(openid, dataEpoch)` 开头，必要时另验证缺失代次字段的 `exists(false)` 查询。旧同步模式仍需 `attempts` 中列出的候选索引，不能提前移除。

## 隔离环境验收条件（目前未执行）

1. 使用独立隔离环境与合成账号、题库和订单；先盘点实际集合、原有规则和索引，确认备份、访问主体和回退方案。不得将本清单误用于生产环境或使用真实数据。
2. 由具备相应权限的操作人员逐集合对照配置并读回规则、索引；验证普通客户端对每个集合的 `get`、查询、创建、更新、删除均被拒绝。分别验证匿名用户、登录用户、其他账号，不能只验证前端隐藏按钮。服务端应仍能通过其身份执行授权业务。
3. 在同一隔离环境中部署相互匹配的候选云函数和客户端，按发布顺序协调 `bankSync`、`studySync` 的受保护读取、旧接口阻断、删除清理，以及小程序开关。验证旧实例不可继续服务，规则、索引、已发布访问策略、超时重试和回退步骤均有读回证据；任一步不满足保持关闭。
4. 使用两个合成账号、免费和付费考试，覆盖未购、模拟权益、到期、续期、退款、跨账号、在途请求、状态修改冲突、网络故障与清空后重试；同时检查管理角色不能越权。验证旧公开接口及历史题目路径不能绕过权限。不要接入真实支付。
5. 用微信开发者工具或测试设备检查页面流程，另在真实 CloudBase 验证索引命中、事务冲突、集合容量、物理清理和数据库规则。已下载到客户端的题目无法保证收回；权限撤销仅影响后续在线请求。

本地 `test/protected-access-plan.test.js` 只检查方案结构和覆盖清单；`test/protected-isolated-acceptance.test.js` 使用内存数据库、内部合成结算和可注入时钟组合真实业务服务。两者都不调用实际 CloudBase 或支付接口，不代表规则引擎、索引、原生微信、云数据库事务或真实资金已验收。
